# 📘 README — Учебный проект ПМ.01  
«Проектирование и разработка информационных систем»
## 1. Направление обучения
Программист
## 2. Описание проекта

Данный проект выполнен в рамках практики по профессиональному модулю **ПМ.01 «Проектирование и разработка информационных систем»**.  
Цель проекта — продемонстрировать навыки анализа предметной области, проектирования архитектуры, моделирования данных, разработки UML-диаграмм и реализации базовой структуры информационной системы.

Репозиторий содержит пример учебного проекта, включающий:

- модели предметной области;
- структуру проекта;
- схемы взаимодействия модулей;
- UML-диаграммы;
- пример доменной сущности;
- пример кода.

## 3. Цели учебного проекта

Проект направлен на формирование компетенций:

- анализ предметной области и выделение сущностей;
- формирование требований и структурирование функций будущей ИС;
- создание UML-диаграмм (Class, Use Case, Component);
- проектирование архитектуры системы;
- разработка модели данных;
- построение структуры проекта;
- документирование решения.

## 4. Формируемые компетенции (по ФГОС СПО 09.02.07)

### Профессиональные компетенции:

- **ПК 1.1.** Анализировать предметную область и собирать требования к ИС.  
- **ПК 1.2.** Проектировать архитектуру и структуру информационных систем.  
- **ПК 1.3.** Разрабатывать модели ИС (UML, ER, BPMN).  
- **ПК 1.4.** Документировать проектные решения.  

### Общие компетенции:
ОК 02, ОК 03, ОК 04, ОК 05, ОК 06.

## 🏗 Состав проекта

### 1. UML-диаграммы

В папке **Docs/** представлены:

- `usecases.puml` — диаграмма вариантов использования;
- `classes.puml` — UML-диаграмма классов;
- `components.puml` — диаграмма архитектурных компонентов.

Диаграммы созданы в **PlantUML** и могут быть рендерены в PNG/SVG.

### 2. Модель предметной области

В папке **Models/** хранится пример сущности:

```csharp
public class DomainModel
{
    public int Id { get; set; }
    public string Name { get; set; } = "";
}
```

### 3. Пример структуры проекта

Минимальная структура программы представлена в `Program.cs`.
